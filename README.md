## How to Run
1. Install Python 3.
2. Clone the repository:
   `git clone https://github.com/laraibnoor911/IR-excersise.git`
3. Run an exercise:
   `python exercise1/starter.py`

(Or open the notebook in Google Colab and run all cells.)
